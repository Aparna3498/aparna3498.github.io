# Aparna Dharmalingam Portfolio

Recruiter-oriented static portfolio for GitHub Pages.

## Publish
1. Create a public repository named `aparna3498.github.io`
2. Extract the ZIP.
3. Upload the files inside this folder to the repository root.
4. Commit to `main`.
5. Settings → Pages → Deploy from a branch → `main` → `/(root)`.
6. Your site will be available at `https://aparna3498.github.io/`.
